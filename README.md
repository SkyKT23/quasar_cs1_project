# Quasar - CS1 Final Project
My final project for my CS1 class (CS 1050) in the spring 2020 semester. It aims to replicate the mini game Quasar (similar to blackjack) from the Mass Effect video games. It is an example of my early work while getting my BS in Computer Science, while
taking my first programming class.

Note: Mass Effect and all associated IP are copyright BioWare Ltd. and Electronic Arts.

Date: May 2020

Known issues: I did not have a firm grasp on object-oriented programming concepts this early in my degree program, so
architecture is weak. I would like to revisit this project to significantly improve the program' structure and implementation.
